# Orientações Monitores · Rua do Lazer

Apresentação interativa de integração dos monitores da Rua do Lazer (Associação Volvo).

- 18 slides com navegação por botões, teclado (← →), deslizar no celular e sumário
- Botões no canto superior direito: **Sumário**, **Baixar PDF** e **Tela cheia**
- Interações: checklists, desafio de vestimenta, sequência de chegada, simulador de chuva, cenários de ocorrência, simulador de intervalos e teste rápido
- Layout adaptado para celular

Abra o `index.html` no navegador para usar.
